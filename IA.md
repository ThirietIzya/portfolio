Pour le développement web de mon portfolio, j'ai décidé d'utiliser Antigravity car c'est une IA directement intégrée dans vs code. J'ai également Google IA Pro, ce qui me permet d'avoir une meilleure performance d'Antigravity.
J'ai commencé mon développement en demandant à Gemini de m'aider à lier Antigravity et Figma car grâce à mon auto-layout je peux donner le lien des composants pour que Antigravity m'aide à le coder quasiment à la perfection. Pour cela j'ai créé un token dans Figma qui m'a donc donné un code secret que j'ai donné à Antigravity.
Pour que Antigravity réalise un code le plus fidèle possible à ma maquette voici le prompt que j'utilise : Utilise l'outil Figma pour lire la structure Auto Layout de ce nœud : https://www.figma.com/design/rhWt8jA2l5kC2LH0jxSnWV/Projet-individuel_Portfolio_Izya_Thiriet_A2?node-id=324-3268&t=RmGiMcBuOePCHWhC-4. Génère le composant correspondant en Astro et Tailwind CSS, puis importe-le proprement dans index.astro.
